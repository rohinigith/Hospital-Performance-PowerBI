# Hospital Performance Power BI Dashboard

An interactive **Microsoft Power BI dashboard** for analyzing hospital-related performance, visitor information, death analysis, and revenue tracking.

## Dashboard Pages

The PBIX report currently contains these report pages:

- **Hospital Performance** — overview/performance analysis
- **Death Analysis** — analysis of death-related data
- **Visitors Information** — visitor-related analysis
- **Revenue Tracking** — revenue analysis and tracking

## Project File

The main Power BI report is:

`Hospital-Performance-Dashboard.pbix`

Open the `.pbix` file using **Microsoft Power BI Desktop**.

## How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Hospital-Performance-Dashboard.pbix`.
4. If Power BI asks for data-source credentials or paths, update the data-source settings for your environment.
5. Refresh the report if required.

## GitHub Note

GitHub stores the `.pbix` file, but it does **not** render a Power BI report directly in the repository page. The PBIX file needs to be downloaded and opened in Power BI Desktop.

For portfolio presentation, screenshots of the dashboard pages can also be added to `docs/assets/` and referenced from this README.
